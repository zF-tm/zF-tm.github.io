# Pixie Dust Attack

## What is it?

The **Pixie Dust Attack** is a much faster way to crack WPS PINs — but it only works on certain vulnerable router chipsets, including:

- Ralink
- Realtek
- MediaTek
- Broadcom

**Why it's fast:** These chipsets have a flaw in how they generate "random" secret numbers (called nonces). Because these numbers aren't actually random — or are predictable — we can figure out the PIN almost instantly instead of trying all 11,000 combinations one by one.

---

## Quick Recap: What Are E-S1 and E-S2?

Earlier, you learned that:

- **E-S1** and **E-S2** are secret 128-bit random numbers generated by the router
- They get combined with parts of the PIN (PSK1, PSK2) and public keys (PKe, PKr) to form two hash values: **E-Hash1** and **E-Hash2**

In formula form:

```
E-Hash1 = (E-S1 nonce value | PSK1 | PKe | PKr)
E-Hash2 = (E-S2 nonce value | PSK2 | PKe | PKr)
```

**Here's the key insight:** We already know PKe and PKr (they're shared openly during the connection process). So if we can figure out E-S1 and E-S2, we can work backward and reveal PSK1 and PSK2 — which together make up the full PIN.

Normally, guessing a 128-bit random number would be basically impossible. But on vulnerable chipsets, these "random" numbers aren't random at all.

---

## Real Examples of the Flaw

### 1. Ralink & MediaTek: The "Always Zero" Bug

Some chipsets never actually generate a real random number — they just use **zero** every single time.

```
E-Hash1 = (E-S1 (0) | PSK1 | PKe (known) | PKr (known))
E-Hash2 = (E-S2 (0) | PSK2 | PKe (known) | PKr (known))
```

Since E-S1 and E-S2 are always 0, and PKe/PKr are already known, the _only_ unknown left is the PIN itself — making it trivial to calculate.

---

### 2. Broadcom: Reused Random Number Generator

Some Broadcom chipsets use the exact same random-number-generating method for multiple values (like the nonce AND the public key).

**The exploit works like this:**

1. Guess the "seed" (starting value) that the router's random generator used
2. Once you find the right seed, you can recreate the same E-S1 and E-S2 values it generated
3. From there, you can calculate PSK1 and PSK2 — the actual PIN halves

---

### 3. Realtek: Predictable Timing-Based Randomness

Some Realtek chipsets generate their "random" values using the **current time** (a Unix timestamp) as the seed. Since these values are all generated close together in time, they often end up being identical — or only slightly different.

```
E-S1 = E-S2 = PKe   (or)   E-S1 = E-S2 = PKe + N
```

**The exploit works like this:**

1. Try different small "guesses" for the time-based seed (the +N difference)
2. This lets you recreate the E-S1 and E-S2 values
3. From there, you calculate PSK1 and PSK2 — the actual PIN

---

## Why This Matters

Compared to traditional online brute-forcing (which can take hours and risks getting locked out after just a few wrong guesses), Pixie Dust attacks:

- ✅ Take **seconds to a couple hours**, not days
- ✅ Require **very few actual PIN guesses** against the router
- ✅ Are much safer against **lockout mechanisms**, since you're not spamming the router with wrong attempts

This makes it the go-to method whenever the target router's chipset is known to be vulnerable.
